关于如何使用GitHub搭建博客

Created2026-10-20|Updated2026-10-20
|Post Views:

由于本人搭建这个博客花费了不少时间，走了不少弯路，所以分享一下搭建过程，给大家避避雷。
一、安装工具
首先要装好两个工具，一个是Git，去官网下载，桌面右键打开Git Bash（没看到就点开更多选项），输入Git –version能输出版本号就算成功。
另一个是Node.js，去官网下载LTS长期支持版。也是在桌面打开Git Bash输入node -v和npm -v检验是否成功。
二、Github
先去注册一个Github账号，打开Git Bash配置身份，分别输入git config –global user.name “你的GitHub用户名”和git config –global user.email “你的GitHub注册邮箱连接你的账号，输入git config –global –list验证是否成功。然后输入ssh-keygen -t rsa -C “你的邮箱”生成SSH密钥，复制密钥到GIthub点头像里的设置，SSH开头的选项，再点New SSH key把你的密钥粘贴进去，保存。
注意：国内想打开Github很不稳定，如果打不开就换个网再试试。
三、生成博客
在电脑里建一个你博客专用的文件夹，右键文件夹打开Git Bash，先安装Hexo输入npm install -g hexo-cli,然后初始化博客：hexo init .,再然后安装依赖：npm install,最后本地预览：hexo server。打开浏览器访问http://localhost:4000就能看到博客初始状态了。
四、部署博客
在Github上创建一个仓库，记住名字必须是用户名.github.io ,然后装部署插件：npm install hexo-deployer-git –save，改配置（在你的文件夹里找到_config.yml）把最底下那几行改成
deploy:
type: git
repo: https://github.com/你的用户名/你的用户名.github.io.git
branch: main
改完保存好就可以正式部署了，打开Github你的仓库，点开设置里的Pages选项按照上面的内容改然后保存，Git Bash里依次输入：hexo clean;hexo generate;hexo deploy。然后你的博客就正式上线了。
五、后续使用
想换主题就在Github上找自己喜欢的主题clone过来就行了。想写文章的话就在Git Bash里输入hexo new”文章题目”，然后找到生成的.md文件打开写就可以了，写完保存，在Git Bash里依次输入：hexo clean;hexo generate;hexo deploy就正式上传你的文章了

以上，就是全部的内容了，还有别的想问的问题也可以来问我或者问AI，本人还是很乐于助人的。
